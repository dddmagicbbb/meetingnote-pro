# Proposal

## Why

새 회의록 팝업에서 녹음을 올리면 회의시각과 본문은 자동으로 채워지지만 제목은 비어 있다. 이때 「정리하기」 버튼이 꺼진 채로 남는데, 버튼 아래 안내 줄이 「본문만 채워짐. 저장은 아직」으로 바뀌어 있어 무엇이 빠졌는지 알 수 없다. 수락 확인 중 실제로 저장을 못 하는 일이 있었다(서버 로그에 업로드 200 두 번, 저장 요청 0번).

## What Changes

- 「정리하기」가 꺼져 있으면 버튼 아래 안내 줄에 빠진 필수 칸 이름을 보인다 (예: 「제목 필수 - 제목을 넣으면 정리할 수 있음」, 「제목 · 본문 필수」)
- 받아쓰기가 끝났는데 제목이 비어 있으면 위 안내를 띄우고 제목 칸에 커서를 옮긴다
- 빠진 칸은 테두리를 붉게(`border-red-dot`, login.html 과 같은 방식) 표시하고, 채우면 바로 지운다
- 서버 동작과 API 는 바뀌지 않는다 (필수값 400 `VALIDATION_ERROR` 는 그대로)

## Capabilities

### New Capabilities

(없음)

### Modified Capabilities

- `meeting`: 새 회의록 팝업의 필수 칸 안내 요구사항을 추가한다 (기존 요구사항 문구는 바꾸지 않음)

## Impact

- `frontend/meetings.html` 의 저장 버튼 상태 · 안내 줄 스크립트만 바뀐다. 마크업 · 클래스 · theme.js 는 그대로
- `backend/tests/e2e/e2e_meetings.py` 에 「제목 없이 받아쓰기만 한 경우」 확인을 추가한다
