# Spec Delta

## ADDED Requirements

### Requirement: 새 회의록 필수 칸 안내
<!-- 근거: C-05 새 회의록 · C-07 받아쓰기 완료 · meetings.html (new, upload-done) · fix-meeting-save-hint (지시) -->
새 회의록 팝업에서 제목 · 회의시각 · 본문 중 빈 칸이 있어 「정리하기」 가 꺼져 있으면, 화면은 버튼 아래 안내 줄에 빠진 칸 이름을 보여야 한다(SHALL). 받아쓰기가 끝난 뒤나 사용자가 칸을 건드리고 비워 둔 뒤에는 그 칸의 테두리도 붉게 표시하고, 채우면 바로 지운다. 받아쓰기가 끝났을 때 제목이 비어 있으면 제목 칸에 커서를 옮긴다.

#### Scenario: 녹음만 올리고 제목이 빈 경우
- **WHEN** 제목을 넣지 않고 `회의_녹음.wav` 를 올려 받아쓰기가 끝나면
- **THEN** 「정리하기」 는 꺼져 있고 안내 줄에 「제목 필수」 가 보이며, 제목 칸이 붉은 테두리로 표시되고 커서가 제목 칸에 있다

#### Scenario: 빠진 칸을 채움
- **WHEN** 위 상태에서 제목을 입력하면
- **THEN** 붉은 테두리와 「제목 필수」 안내가 사라지고 「정리하기」 가 켜진다

#### Scenario: 팝업을 막 연 상태
- **WHEN** 팝업을 열고 아무것도 넣지 않아 회의시각만 자동으로 채워져 있으면
- **THEN** 안내 줄에 「제목 · 본문 필수」 가 보이고 붉은 테두리는 아직 없다
